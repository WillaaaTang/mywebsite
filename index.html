WEEK 03

WORKSHOP REFLECTION · WEBSITE SETUP

Making a space on the web

Setting up my portfolio helped me understand that a website is made from files, such as HTML for the content and CSS for the appearance. GitHub stores the project files in a repository, and GitHub Pages can publish those files as a website.

Before this, I mostly thought of the Internet as a place where I visit finished pages. This process showed me a little more of what happens behind the scenes: pages are built from files, stored somewhere, and sent to a browser when someone visits a link. I am still learning how the different parts connect.

Next step: Keep adding small updates and reflect on what changes when I publish them online.
